# 要望シートメーカー

バンドのPA要望・照明要望・セット図を、公演ごとに組み替えてA4で出力するWebツールです。
`index.html` 1枚で動きます（ビルド不要）。

## 使い方

- `index.html` をブラウザで開くか、GitHub Pages で公開して使います。
- データはそのブラウザ（localStorage）に保存されます。端末を変えるときは「バックアップを書き出す」で JSON を保存してください。
- 「A4シートを保存（HTML）」で保存したファイルを開き、印刷 → PDFに保存（A4・余白なし）します。

## 公開（GitHub Pages）

Settings → Pages → Branch を `main` / `/ (root)` にして保存します。
