# 要望シートメーカー

バンドのPA要望・照明要望・セット図を、公演ごとに組み替えてA4で出力するWebツールです。
`index.html` と `library.json` で動きます（ビルド不要）。

## 使い方

- 公開URLをブラウザで開いて使います。
- セットリストや公演情報は、そのブラウザ（localStorage）に保存されます。端末を変えるときは「バックアップを書き出す」で JSON を保存してください。
- 「A4シートを保存（HTML）」で保存したファイルを開き、印刷 → PDFに保存（A4・余白なし）します。

## 曲ライブラリの共有

曲ライブラリは `library.json` が共通の元データです。ページを開くたびに読み込み、メンバーのPCに足りない曲を追加します。曲の内容を直したときは、`rev` が新しくなった曲だけ上書きされます。

更新の手順（管理する人）:

1. ツールの「曲ライブラリ」タブで曲を追加・修正する。
2. 「共有用に書き出す（library.json）」を押して保存する。
3. このリポジトリの `library.json` を、保存したファイルで置き換えて Commit する。
4. 公開サイトが自動で更新される。メンバーはページを開き直すと反映される。

`index.html` をそのままダブルクリックで開いた場合（file://）は `library.json` を読み込めないので、内蔵の曲だけが出ます。
