# 要望シートメーカー

バンドのPA要望・照明要望・セット図を、ライブごとに組み替えてA4で出力するWebツールです。
`index.html` と `library.json` で動きます（ビルド不要）。

## 使い方

- 公開URLをブラウザで開いて使います。
- セットリストやライブ情報は、そのブラウザ（localStorage）に保存されます。別のPCには引き継がれません。
- 「A4シートを保存（HTML）」で保存したファイルを開き、印刷 → PDFに保存（A4・余白なし）します。

## 曲ライブラリの共有

曲ライブラリは `library.json` が共通の元データです。ページを開くたびに読み込み、メンバーのPCに足りない曲を追加します。曲の内容を直したときは、`rev` が新しくなった曲だけ上書きされます。

更新の手順（管理する人）:

1. GitHub上で `library.json` を開き、曲を追加・修正する（鉛筆アイコンで編集）。
2. 曲の内容を直したときは、その曲の `rev` を今より大きい数に上げる。新しい曲は `id` を重複しない値にして、`rev` を 1 以上にする。
3. Commit する。公開サイトが自動で更新され、メンバーはページを開き直すと反映される。

`index.html` をそのままダブルクリックで開いた場合（file://）は `library.json` を読み込めないので、内蔵の曲だけが出ます。
